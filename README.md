## 📦 How to Deploy to `daipayanghosal.github.io`

Because the website is built with vanilla HTML5, CSS3, and ES6 JavaScript, it has **zero build steps** and works directly with GitHub Pages:

1. Open your terminal or Git bash inside this folder (`Portfolio`).
2. Initialize and push to your GitHub Pages repository:
   ```bash
   git init
   git add .
   git commit -m "feat: complete remodel with Sentinel-X cyber HUD, AI Threat Lab & Executive Dossier"
   git remote add origin https://github.com/daipayanghosal/daipayanghosal.github.io.git
   git branch -M main
   git push -u origin main --force
   ```
3. Your live website will immediately update at **`https://daipayanghosal.github.io`**!
