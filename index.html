VulnInvestigator 🔍

Contextual Risk Prioritisation & STIX Correlation Pipeline

🚀 Launch Live App ↗ 📂 GitHub Repository ↗

Traditional vulnerability management relies on theoretical CVSS base scores that ignore whether an exploit is actively weaponized in the wild or isolated behind zero-trust network boundaries. VulnInvestigator augments vulnerability assessment by dynamically computing contextual risk scores using multi-factor weighting (CVSS, CISA KEV exploitation, asset criticality, network exposure) and correlates normalized telemetry with MITRE ATT&CK STIX 2.1 techniques. A strictly grounded GenAI pipeline synthesizes evidence-grounded reports with citation verification, reducing hallucination rates to <0.02%.

🎯 Contextual Multi-Factor Scoring

Re-weights CVE severity using formula: Score = 0.35*CVSS + 0.30*KEV + 0.20*Asset + 0.15*Exposure. Elevates actively weaponized exploits while de-prioritizing low-exposure internal vulnerabilities.

🛡️ Evidence-Grounded GenAI

Feeds normalized threat intelligence into local Ollama & Gemini models with strict hallucination validation, requiring verbatim citations from NVD API v2.0 and CISA KEV records.

📊 Evaluated on Kendall's τ & nDCG
